# SplitStack

Shared expense management app.

## Requirements

- [Node.js](https://nodejs.org) (includes npm)

To check if you have it:
```bash
node --version
npm --version
```

If not installed, run:
```bash
brew install node
```

---

## Running the Frontend

```bash
cd website/frontend
npm install
npm run dev
```

Then open **http://localhost:5173/** in your browser.

> `npm install` only needs to be run once, or after pulling new changes.

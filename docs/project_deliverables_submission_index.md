## Recommended Files and Folders to Submit

Submit the full repository when possible. If the submission system requires selecting individual items, include:

- `planning files/` for supporting original planning artifacts
- `docs/` for the Markdown documents listed above
- `website/`
- `mobile-app/`
- `README.md`
- `Mobile_receipt_scanning.mov`

## Document Versions

The original Word/PDF planning files in `planning files/` are useful historical artifacts. For grading, use the as-built Markdown documents in `docs/` because they reflect the current implemented system and verification results.

## Notes

- The `planning files` folder alone does not include the source code, release notes, diagrams, test plan/results summary, or standalone build/deployment instructions.
- Mermaid diagrams are included in Markdown files. GitHub and many Markdown renderers display Mermaid diagrams automatically.
- The project has no formal git release tags. `docs/project_release_notes.md` lists what is included in this handoff.
